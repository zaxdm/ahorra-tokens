# Gastar menos en el chat de claude.ai

En el chat de claude.ai (la web y la app de escritorio o del celular) no hay archivos de configuración:
todo se ajusta a mano en tu cuenta. Cada mensaje vuelve a enviar todo lo que el chat ya tiene: la
conversación, los archivos, las instrucciones del proyecto y las herramientas de los conectores
activos. Cuanto menos cargue cada mensaje, más te dura el límite.

## 1. Apaga los conectores que no usas

Las herramientas de cada conector activo se cargan aunque no las uses.

- En **Configuración → Conectores**, desconecta los que no usas nunca.
- En cada chat, en el botón **+**, apaga los que no necesitas para esa conversación.
- Si dos conectores hacen lo mismo, deja uno.

## 2. Apaga las skills que no usas

En **Configuración → Capacidades** (o **Personalización → Skills**), desactiva las skills que no usas.
Cada una suma su descripción a todos tus chats.

## 3. Un chat por tarea

Un chat largo es caro: cada mensaje nuevo arrastra todos los anteriores.

- Cuando cambies de tema, abre un chat nuevo.
- Si un chat ya está muy largo, pide un resumen de lo importante y sigue en un chat nuevo con ese resumen.

## 4. Proyectos con poco peso

Las instrucciones y los archivos del proyecto se cargan en todos sus chats.

- Instrucciones cortas: solo lo que Claude no puede adivinar.
- Sube solo los archivos que hacen falta. Mejor un resumen de 2 páginas que un PDF de 200.

## 5. El modelo justo

- Para dudas rápidas, correcciones o resúmenes, usa un modelo más ligero o menos esfuerzo.
- Deja el modelo más potente para lo difícil.
- El razonamiento extendido gasta más: actívalo solo cuando haga falta.

## 6. Archivos e imágenes

- Recorta las capturas a la parte que importa.
- Pega el fragmento de texto que importa, no el documento entero.
- No vuelvas a subir el mismo archivo en el mismo chat.

## Si tienes más de una cuenta

Esta configuración es por cuenta: hay que repetirla en cada una. Los chats no pasan de una cuenta a
otra. Lo que sí puedes copiar son las instrucciones del proyecto y tus archivos.
